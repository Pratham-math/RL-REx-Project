01

What we changed

Progress feedback

An incomplete repair can still improve a program. We added a small reward for a positive change in its repair-test score.

Estimated token cost

We adjusted the selection priority using the estimated cost of the next request. Actual spending is measured separately from the model’s token counts.

These changes affect candidate selection. The language model’s weights stay fixed.
