The interrupted task

The first GPU campaign stopped during a request on test/0146. Its response was not saved, so that request remains unknown in the original record.

Before replacement inference and hidden evaluation, we fixed a rule: rerun that entire problem for all three methods, regardless of the outcomes. The comparison uses those three fresh trials and the twelve unaffected original trials.

The original runs were preserved. Source experiment IDs and checkpoint mappings are retained in the composition record. This was a replacement task run, not a claim that the lost response had been recovered.

What to measure next

  1. Separate the components

    Run progress-only and cost-only policies to identify their individual effects.

  2. Use more development tasks and seeds

    Test whether richer feedback and longer budgets produce different search trajectories.

  3. Freeze a final protocol

    Select settings on development data, then evaluate a separate held-out task set without retuning against its hidden scores.
