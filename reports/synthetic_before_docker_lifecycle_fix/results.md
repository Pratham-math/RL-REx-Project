# Synthetic verification

Synthetic fixtures verify plumbing and calculations; they establish no comparative model performance.

Model: synthetic-script. Exact setup: resolved_config.json, seal dc106c56dccf5d7d52d860240e8b7e038819950cebd0b192e76924b5e23333a0.

1 tasks; 2 seeds; task bootstrap 95% CI. All methods use the same prompts, parser, repair tests and limits.

Success is correctness of the repair-selected returned solution on every hidden test. Call AUC is the arithmetic mean over all integer call checkpoints. Token curves use completed-generation prefixes; crossing requests remain charged to the campaign. Null tokens-per-success means undefined (zero successes), never zero cost.

Progress credit is fractional pseudo-count shaping, with no inherited Bernoulli-posterior or optimality guarantee. This restricted stdio APPS study is not an official APPS score or full-paper reproduction. Public contamination, finite repair coverage, model seed behavior, nondeterministic programs, and near-duplicate tasks limit interpretation. Component comparisons are exploratory.
